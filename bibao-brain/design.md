# 比宝拟人化优化设计

## 1. 问题

当前脑核已有神经状态、关系、记忆、生活流和自我复盘，但中文情感评估主要依赖关键词。它会把“你是不是觉得我很烦”判作攻击，也可能把倾诉、邀约、告别等不同对话动作混成普通问句。模型还可建议与算法不同的动作路由，令决策边界不够清楚。

## 2. 目标与范围

让回复更能接住语境，同时保留状态、关系和人格带来的不一致性与边界。新增可解释的对话动作特征和本地回应策略；明确由算法决定路由、安全相关状态变化和外发动作，语言模型主要负责自然表达。明确类别之外仍走现有逻辑。

本次不引入外部语料、训练模型或运行时依赖，不改 QQ 连接/发送配置，不声称规则分类等同于理解或意识。

## 3. 可选方案

### A. 扩充固定话术

按情绪和关系继续堆模板，成本最低、输出稳定；但只能增加词条，无法可靠区分“普通问句”和“想被陪伴”，模板感会随覆盖面增长。

### B. 所有判断交给 LLM

语义弹性最好，但增加延迟、调用成本与不可复现性；模型可能改变沉默、转述或关系边界等动作决定。

### C. 规则分类 + 状态机裁决 + LLM 表达（推荐）

对高置信常见对话动作使用本地中文规则，为低置信/复杂/高风险输入保留 appraisal 模型；布洛卡根据分类、关系、状态和人格生成或校准表达。路由、神经状态变化及外发动作由确定性逻辑钳制。这个方案增加有限的规则维护成本，但可测试、低延迟，并保留模型的语言弹性。

## 4. 关键行为

- 识别求安慰、求陪伴、邀约、夸奖、感谢、告别、倾诉、抱怨等常见语用动作，并输出启发式置信度。
- 处理否定/上下文线索，避免将自我怀疑词误当辱骂；未知文本沿用现有分类。
- 本地语言区按动作、社会面具、情绪和能量选择短回应。模型不输出气泡时，用本地回应补齐；预算与复读过滤继续生效。
- 算法最终决定回复/沉默/转述路由、关系/激素增量、等待回复与撤回钩子。被模型改写的提议只供审计。转述没有可用接收者时沉默。
- 对明确且高置信的语用动作跳过额外 appraisal 调用；歧义、强敌意或越界问题仍调用。

## 5. 架构与风险

改动集中在 `core/appraisal.js`、`core/broca.js`、`core/prefrontal.js` 和 `core/brain.js`，回归放在 `bin/growth-smoke.mjs`；按需更新盲评文档。规则误分类会造成不合时宜的安慰或邀约回应，因此类别采用有限集合，保留低置信回落，并覆盖否定、普通问候、抱怨及能量/关系差异。转述路由需要确保存在合适的接收对象。

## 6. 验收标准

- 新增语用分类与本地回复测试通过，包括用户给出的“我今天有点累，想听你说说话”场景。
- LLM 不能把算法的沉默变为回复，不能把回复变成私聊转述，也不能更改算法控制的关系/激素增量及撤回/等待钩子。
- 已有 `sandbox.mjs`、`growth-smoke.mjs`、`host-smoke.mjs` 与 `eval-qq.mjs` 无回归；检查盲评输出不把投诉误判成接受邀约。
- 对比旧版与新版 20 场景样本；自动测试只证明规则与接口行为，不代替人工盲评。
