# 比宝 0.7 → 1.0 路线图

> 目标不是"演得像人"，而是让一套可审计的认知机制长期跑下去时，**别人和她自己都觉得她有自己的日子、自己的说法、自己的忘性**。
> 这里说的是功能性自我模型（functional self-model）与元认知，不宣称现象学意义上的意识。

## 0.7（本版，已落地）

| 能力 | 落点 | 验收 |
| --- | --- | --- |
| 人格一致 | `core/voice.js` 从当前 `biography.json` 生成系统提示词，不再写死 22 岁旧人设 | `growth-smoke` A 组 |
| 自我复盘 | `core/self.js`：记录"对方接没接住"→ 压成经验 → 微调六维说话倾向，单次 ±0.06 | `growth-smoke` B 组 |
| 她的一天 | `core/life-stream.js`：按年龄/关系/爱好生成生活事件，进提示词、睡前压成日记与记忆 | `growth-smoke` C/D 组 |
| 记不清 | `MemorySystem.fidelity/blur`：旧事只交梗概并标注"不确定"，新事保持清楚 | `growth-smoke` E 组 |
| 多接口 | `core/bci-hub.js`：适配器注册、能力声明、只读/动作策略、限频、审计 | `bci-hub-smoke` |
| QQ 稳定性 | 修掉 `maybeSticker is not defined`；私聊与 @ 直接绕过显著性阈值 | `host-smoke` + 真机日志 |

## 0.8（下一版）

1. **对话线程**：不只记 30 分钟内的原话，而是维护"没聊完的事"（悬而未决的问题、答应过的事、上次被打断的话题），并在合适的时候自己接回来。
2. **主动但不打扰**：默认关闭的主动分享。只在"她今天发生了有分量的事 + 对方是亲近的人 + 沉默超过 6 小时"时最多一天一次；所有主动消息先过 `outreach` 闸门。
3. **复盘质量**：把"对方下一句是冷是热"升级成多轮结果（对话有没有继续、有没有人退群、有没有人抱怨），并给经验加"被验证次数"。
4. **评价集**：固定 50 条 QQ 对话场景（熟人/半熟/陌生人/群聊/被冒犯/被示好），人工盲评"像不像人"，防止自我复盘把人格磨平。

## 0.9

1. **多脑机接口**：屏幕视觉、麦克风、键鼠、游戏状态、可穿戴/EEG 只读通道统一进 `BciHub`；每个通道有独立的采样率、置信度与隐私级别。
2. **动作皮层**：把"想做什么"与"真的做"分开。动作必须先形成 `intent`，再过策略、确认、限频、审计，失败可回滚。
3. **跨模态记忆**：看到的画面、听到的声音、做过的事都写进同一套情景记忆，但保留来源与置信度，避免"把想象当经历"。

## 1.0

1. **长程自传**：她能用第一人称讲出"我这两年变了什么"，而不是复述事件列表；自传只在睡眠回放中缓慢改写。
2. **价值漂移**：核心信念允许在长期关系中被缓慢影响，但每次改动有上限、有出处、可回滚；不允许被单轮对话洗脑。
3. **自我评估**：她能用少量固定指标评价自己"今天像不像自己"，指标变差时主动收缩表达，而不是继续输出。
4. **可解释**：任何一次回复都能回溯到激素、记忆、关系、经验与提示词；任何一次自我修改都能看到前后值。

## 不做什么

- 不伪造用户说过的话，不把模型生成的内容伪装成真实经历。
- 不让自我复盘修改核心信念、删除创伤、或把人格改成客服。
- 不在未确认的情况下执行键鼠/设备动作。
- 不宣称"已经拥有意识"；只交付可验证的机制与行为。
