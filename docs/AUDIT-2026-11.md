# 比宝插件审计记录

日期：2026-11-26
基线：GitHub `main` / 插件 `0.19.3`

## 已修复

- 修复最新版同步后 `bibao-brain/bin/sticker-onebot-smoke.mjs` 的 UTF-8 BOM，避免 Node 直接语法检查失败；同时清理同类 Node smoke 文件 BOM。
- 修复自动感官采样间隔更新后 `/bci`、`/senses` 和状态快照仍返回启动时旧间隔的问题。现在读取运行时配置。
- 修复视觉使用 DSH 已登录模型或自定义供应商时，状态页仍按直连 `apiKey` 判断 `hasKey` 的问题；状态现在按实际生效模式显示。
- 修复前端把 POST body 复制进 `payload` 查询串造成敏感配置进入 URL、代理日志和浏览器历史的问题。设置、供应商、模型和视觉配置请求不再复制到 URL。
- 收紧独立控制台 Cookie 校验，要求完整的 `bibao_ui=<token>` 字段，不再接受带有效 token 前缀的伪造值。
- 修复视觉 data URL 不限大小/格式校验的问题。直连和 DSH 视觉路径现在统一限制 8 MB，并只接受 PNG/JPEG/GIF/WebP。
- 修复 `/settings` 复合请求的部分应用：主人 QQ、视觉模型名和普通模型名的可失败校验现在发生在任何设置修改之前。
- 清理自动系统感官适配器的重复 `readOnly` 属性。

## 剩余风险

- 反向 WebSocket 实现只覆盖 OneBot 当前需要的文本帧、ping/pong 和 close；未实现 WebSocket continuation 分片。当前 OneBot 测试链路使用单帧文本，若接入会主动分片的客户端，需要补协议测试。
- 系统本体感觉的前台窗口标题与电源信息使用同一次 PowerShell 采样缓存，最长可能滞后 5 分钟；这是采样开销与实时性的折衷。
- 本轮未开启真实 DSH/QQ 账号，也没有启用键鼠动作；动作层仍保持关闭。
